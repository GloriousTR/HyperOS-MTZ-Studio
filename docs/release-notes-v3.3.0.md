# HyperOS MTZ Studio v3.3.0

This release makes rootless setup clearer while preserving the established Root and Shizuku/Shevery theme workflows.

## Highlights

- Keeps the existing Root workflow unchanged.
- Requires Shizuku or Shevery for reliable theme application on non-rooted devices.
- Recommends Shevery only when neither compatible authorization manager is installed.
- Improves the Wireless debugging pairing tutorial: its steps remain scrollable while **Developer options**, the **official illustrated guide** and **Close** actions stay visible on screen.
- Links directly to Shizuku's official illustrated Android setup instructions instead of showing invented or device-specific menus.
- Includes direct Telegram support through [@Glorioustr](https://t.me/Glorioustr) and detailed Live Diagnostics export.
- Retains automatic Shizuku theme persistence monitoring and repair for protected themes.
- Retains BAK Converter, Theme Language Tool, MTZ library, Theme Composer and 20 interface languages.

Local MTZ import, preview, translation, composition and export remain available before authorization. Applying a theme on a non-rooted device requires Shizuku or Shevery to be running and authorized.
