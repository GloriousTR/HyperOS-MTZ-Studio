# HyperOS MTZ Studio v3.2.0

v3.2.0 refines the rootless experience while preserving the adaptive Root, Shizuku/Shevery and Xiaomi Themes integration introduced in v3.1.0.

## Highlights

- **Cleaner rootless apply:** tapping Apply now prepares the safe public MTZ copy and proceeds directly to Xiaomi Themes without MTZ Studio's redundant confirmation dialog.
- **BAK Converter:** supported Xiaomi Themes backups are reconstructed as portable MTZ packages without replacing Theme Manager data.
- **Optional conversion translation:** preserve the source language or translate supported visible text into the active app language.
- **Higher-quality translation:** multilingual XML, JSON and safe MAML coverage, translation memory, reviewed Chinese terminology, optional user-configured API providers and offline fallback.
- **Clean organization:** complete themes remain in Themes while font-only resources are routed to Fonts.
- **20 interface languages** with system-language, RTL and per-app language support.

## Compatibility note

MTZ Studio removes only its own duplicate confirmation. Xiaomi controls the final system import/apply surface, so a Xiaomi screen or manual confirmation may still be required on some ROM and Themes versions. Standard rootless protection remains best-effort; stronger private-catalog operations require Shizuku/Shevery or Root where supported.

v3.2.0 uses the stable signing key introduced with v2.1.0 and supports normal in-place upgrades from compatible recent releases.
