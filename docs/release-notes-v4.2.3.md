# HyperOS MTZ Studio v4.2.3

## Shizuku/Shevery tema uygulama düzeltmesi

- Shizuku/Shevery ADB modu etkin olan cihazlarda modern Xiaomi Temalar akışı artık yanlışlıkla root erişimi istemez.
- 10.8.7.6 ve üzeri Temalar sürümlerinde MTZ, doğrulanmış ortak kopyası üzerinden Shizuku ile modern yerel içe aktarma alanına hazırlanır.
- Köprü uygun değilse Xiaomi Temalar’ın yerel kitaplığı güvenli biçimde açılır; kullanıcı son içe aktarma ve uygulama onayını burada tamamlar.
- Modern hazırlama, geçici dosya temizliği ve hata tanılama işlemleri Shizuku kabuğunu destekler.
- Root modu ile eski Global Temalar sürümlerinin mevcut yolları korunmuştur.
