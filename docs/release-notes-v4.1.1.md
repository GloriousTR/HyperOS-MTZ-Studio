# HyperOS MTZ Studio v4.1.1

v4.1.1 fixes automatic update package selection and keeps the recommended Xiaomi Themes APK linked to its stable v4.0.0 release asset.

## Changes

- Automatic updates now select only the MTZ Studio APK and matching checksum.
- Xiaomi Themes helper APK is no longer copied into every new release.
- The recommended Themes 3.0.5.6 download continues to use the stable v4.0.0 asset.
