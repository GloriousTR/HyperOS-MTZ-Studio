# HyperOS MTZ Studio v4.2.4

## Canlı güncelleme indirme akışı

- Güncelleme denetleme penceresi artık yalnızca geçerli sonucu gösterir: en güncel sürüm veya bulunan yeni sürüm.
- Yeni sürüm bulunduğunda APK indirme yüzdesi uygulama içinde canlı bir ilerleme çubuğunda gösterilir.
- Aynı indirme yüzdesi arka plan bildiriminde de güncellenir.
- GitHub Release dosya boyutu kullanılarak yavaş bağlantılarda dahi güvenilir ilerleme bilgisi sunulur.

## Okunabilir ilerleme çubukları

- Çeviri düğmesi ve güncelleme ekranı ortak, kontrast duyarlı ilerleme çubuğuna geçirildi.
- Dolan alan metne ulaştıkça yalnızca dolu bölüm üzerindeki yazı rengi değişir; yüzde değeri açık ve koyu temalarda okunabilir kalır.
- Güncelleme indirme metni desteklenen 20 uygulama diline eklendi.
