# HyperOS MTZ Studio v4.0.2

v4.0.2 completes the v4 compatibility update and fixes multi-file MTZ selection on Xiaomi/HyperOS file pickers.

## Changes

- Uses the system multi-content picker for selecting several MTZ files on HyperOS.
- Accepts one to five distinct MTZ files from the multi-selection result.
- Keeps the per-file and overall import progress display on the MTZ Import screen.
- Includes the 10.8.7.6+ native Xiaomi Themes library compatibility detection introduced in v4.0.1.
- Preserves all legacy Global, Root, Shizuku and Shevery workflows.
