# HyperOS MTZ Studio v3.3.1

This maintenance release adds direct access to the Shizuku/Shevery setup video from inside the app.

## Highlights

- Adds a permanently visible **Watch the video tutorial** action to the in-app wireless debugging guide.
- Opens the shared YouTube setup video directly, alongside the official illustrated guide and Android Developer options shortcut.
- Keeps the Root and Shizuku/Shevery theme workflows unchanged.
- Retains BAK Converter, Theme Language Tool, theme persistence monitoring, Telegram support and 20 interface languages.

On non-rooted devices, applying themes still requires Shizuku or Shevery to be running and authorized.
