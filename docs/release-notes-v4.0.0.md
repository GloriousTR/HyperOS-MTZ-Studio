# HyperOS MTZ Studio v4.0.0

v4.0.0 introduces a redesigned workspace that keeps the established Root and Shizuku/Shevery workflows while making device status, compatibility and theme tools easier to understand.

## What changed

- Added the new four-section interface: **Panel**, **Library**, **Create Your Theme** and **Tools**.
- Rebuilt the Panel with live authorization details, the detected root manager or Shizuku/Shevery status, Xiaomi Themes compatibility and compact quick actions.
- Redesigned the Library around the currently applied theme and a cleaner saved-theme gallery.
- Added a dedicated MTZ Import page with separate single-file and multi-file selection. Batch import supports up to five MTZ files and shows live overall progress.
- Matched the Backup quick action to the other Panel modules and kept backup access in one clear location.
- Refined Default and Aero Glass appearances, light/dark/AMOLED modes, card contrast and the floating bottom navigation.
- Updated Live Diagnostics and the Theme Language Tool to use the same visual system.
- Preserved Root, Shizuku/Shevery, BAK Converter, translation, cloud backup, secure update and theme-persistence capabilities.

## Requirements

- Android 8.0 or newer.
- Root mode uses the detected root manager when available.
- Shizuku or Shevery is required for supported non-root theme-application workflows.
- Xiaomi Themes compatibility still depends on the installed ROM and Themes package; Studio reports the detected status before import.
