# HyperOS MTZ Studio v3.4.1

v3.4.1 refines the theme-card translation interface introduced in v3.4.0.

## What changed

- Removed the separate progress bar between the Apply and Translate/Delete controls.
- Translation progress now appears directly inside the Translate button with a compact activity indicator and percentage.
- Background translation and Android notification progress continue to work unchanged.
- Includes the portable cloud backup and securely verified GitHub update system introduced in v3.4.0.

## Requirements

- Android 8.0 or newer.
- Root, or Shizuku/Shevery authorization, is required for privileged Xiaomi Themes operations.
