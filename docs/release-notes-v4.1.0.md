# HyperOS MTZ Studio v4.1.0

v4.1.0 makes Shizuku/Shevery setup easier for first-time users and replaces the unreliable system multi-file gesture with an in-app MTZ selection flow.

## Changes

- Adds a guided Shizuku/Shevery setup wizard that detects the missing step automatically.
- Keeps a persistent “Return to MTZ Studio setup” notification until authorization is ready.
- Opens the relevant Android settings or service manager directly from each setup step.
- Adds an in-app checkbox picker for importing up to five MTZ files from a selected folder.
- Makes the multi-MTZ action a prominent filled button.
- Keeps per-file and overall progress reporting during batch imports.
- Preserves the existing Root, Shizuku, Shevery and Xiaomi Themes compatibility workflows.
